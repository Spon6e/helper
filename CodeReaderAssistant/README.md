# Code Reader Assistant

Небольшое Windows-приложение для локального перевода и пояснения выделенного кода.

## Возможности

- быстрый перевод слова или короткой фразы с английского на русский без ключей и регистрации;
- расширенные пояснения базовых конструкций, стандартной библиотеки и популярных модулей Python/C++;
- автоматическое чтение выделения из редактора без горячих клавиш;
- ручная вставка текста из буфера обмена;
- окно всегда поверх других окон;
- локальная память результатов и пользовательских заметок;
- кнопка `Пересчитать`, если нужно заново обработать сохранённый текст.

## Первый запуск

Запустите `CodeReaderAssistant.exe`. Приложение не требует AI-сервиса, API-ключа или подключения к интернету.

Выберите режим и язык, затем выделите текст в любом редакторе. Приложение попробует прочитать выделение через Windows UI Automation и сразу покажет результат.

Если редактор не отдаёт выделение автоматически, нажмите `Ctrl+C`, а затем `Взять из буфера`.

Для одного слова переводчик показывает одну короткую строку вида `name → имя`. Он также переводит распространённые имена переменных и классов в форматах `user_name`, `userName` и `UserManager`. Для предложения он сохраняет исходную структуру текста и не добавляет примеры или длинные пояснения. Незнакомые слова сохраняются как есть.

Пояснялка использует расширенную встроенную справочную базу, распознаёт структуру фрагмента и знает основные ключевые слова, контейнеры и стандартные модули. Она не обращается к AI и не знает абсолютно все специфичные команды сторонних библиотек.

Результаты и заметки сохраняются в `%LOCALAPPDATA%\CodeReaderAssistant\memory.json`.

## Сборка

Нужен установленный .NET 9 SDK для Windows:

```powershell
dotnet build
dotnet run
```
